MD040A supports the following EVMs with the DDW package of the device.
- DRV8462EVM (MD040 Variant 002)
- DRV8962EVM (MD040 Variant 004)
- DRV8262EVM (MD040 Variant 006)
- DRV8461EVM (MD040 Variant 007)

MD041A supports the DDV package (flip-chip) version of these EVMs, which has the 
thermal pad on top of the chip and the EVM has a heatsink attached to it.
- DRV8462VEVM (MD041 Variant 001)
- DRV8962VEVM (MD041 Variant 002)
- DRV8262VEVM (MD041 Variant 003)

MD040E2 was the initially released version of DRV8462EVM and DRV8962EVM with 
   pre-production silicon on it.  
MD040A is the updated version which has production silicon on it, along with 
   some minor silkscreen improvements and other small fixes. It also has 
   variant 007 for DRV8461EVM

All of these EVMs use the same GUI which can be found on dev.ti.com titled "DRV84xx_DRV82x2_DRV89x2-EVM-GUI" https://dev.ti.com/gallery/view/MotorDriversBSM/DRV84xx_DRV82x2_DRV89x2-EVM-GUI/
